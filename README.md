# Rupee Volume Indicator (Pine Script)

This indicator calculates **volume in currency value (₹)** instead of just quantity. Useful for spotting smart money participation using price × volume turnover logic.

## Features
- Custom display units: ₹ / K / Lakhs / Crores
- Price or volume-based bar coloring
- Overlay = false (traditional volume panel)
- Moving average line (SMA/EMA)
- Clean info table on the left side
- Left-side table with last traded bar volume + average
